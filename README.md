# Snap Tool

Windows x64 桌面区域截图工具。使用 C#、WPF 与 Windows 原生 API，支持区域录屏、手动滚动长截图、矩形、箭头、序号与马赛克标注、置顶贴图、本地离线中英文 OCR 和有道在线文本翻译。

源码仓库：[snailMai/snap-tool](https://github.com/snailMai/snap-tool) 。

## 使用

按下方“开发与构建”生成便携包后，运行 `dist/SnapTool/SnapTool.exe`，程序驻留系统托盘。

若旧版已经运行，先右键其托盘图标选择“退出”，再启动新版目录中的 `SnapTool.exe`；程序只允许一个实例。

1. 按 **Ctrl+F2**，鼠标指向窗口时自动显示该窗口大小的选框；单击固定选区，也可直接按住鼠标拖动，自行框选区域。
2. 松开鼠标后，直接拖动截图框边缘或角点调整大小；未启用标注工具时，拖动框内移动，在外部拖动重新框选。
3. 按 **Ctrl+C**、**Enter** 或点击“复制”，将图片放入剪贴板。Enter 仅在截图画面且不带修饰键时复制；焦点位于工具栏控件时保留控件自身的确认行为。未启用标注工具时，也可双击选区内部复制。
4. 按 **Ctrl+S** 或点击“保存”，选择 PNG 保存位置。
5. 按 **Shift+C** 或点击“OCR”，识别调整后的选区。成功后复制文字并结束截图，在记事本或其他输入框按 **Ctrl+V** 查看结果。
6. 按 **Shift+T** 或点击“翻译”，先本地识别，再打开原文／译文对照窗口并请求有道翻译。默认译为简体中文，可选择英文；修改原文或目标语言后点击“翻译”重新请求。
7. 按 **Esc**、右键选区画面或点击“取消”，结束本次截图；识别过程中也可以取消。对照窗口中按 Esc 取消当前请求，空闲时按 Esc 关闭窗口。

Shift+C 仅在截图窗口内生效。OCR 在本机执行，不上传截图、不保存识别历史。识别过程中显示状态并禁用重复操作；无文字或失败时保留选区和原剪贴板，取消后不会输出迟到结果。结果保留识别出的换行，但不保证还原表格、多栏排版或代码缩进；小字、模糊文字可能识别不准。

## 自动识别窗口

- 开始截图后，选框随鼠标匹配指向的可见顶层窗口；窗口重叠时优先匹配鼠标位置最上层的窗口。识别的是整个窗口，不细分按钮或面板。
- **单击**固定窗口选区并显示工具栏；**按住拖动**直接改为手动框选。小幅手抖不会将单击变成拖动，确认前复制、贴图和 OCR 不会输出内容。
- 固定选区后不会继续自动吸附，可拖动边缘调整大小，或使用矩形、箭头、序号、马赛克、复制、保存、OCR、翻译及贴图。
- 隐藏、最小化及其他虚拟桌面上被 DWM 隐藏的窗口不参与匹配；没有识别到窗口时可手动框选。超出桌面的窗口边界会被裁剪。
- 窗口位置和层级以开始截图时为准，图片仍来自当时可见的桌面；不会恢复窗口被其他窗口遮挡的内容，也不会自动切换或放大实际应用窗口。

## 矩形、箭头与序号标注

长截图操作见下方“滚动长截图”；长截图需要未添加标注的内容选区。

1. 按 **Ctrl+F2** 框选截图后，点击 **矩形** 或 **箭头**，在选区内拖动绘制。箭头从按下位置指向松开位置。
2. 按住 **Shift**：新矩形限制为正方形；箭头绘制或端点调整时限制为水平、垂直或 45°。默认红色、粗细档位 8 px。矩形按该像素宽度绘制；箭头使用尖尾、渐宽线身和两侧凹角的实心轮廓，粗细档位控制整体宽度和头部大小。短箭头按长度缩小，长度不足 2 px 不保留。
3. 点击框线或箭头选中标注，拖动它们整体移动；选中矩形有八个缩放控制点，箭头有两个端点。各标注工具均可选中和编辑已有图形，空白处绘制当前工具的图形；矩形内空白支持嵌套。
4. 工具栏可选择红、黄、绿、蓝、白、黑，以及 2／3／5／8 px 粗细。选中标注时立即修改该标注，同时作为后续新图形的样式。
5. 按 **Delete** 删除选中标注，工具栏不设删除按钮；按 **Ctrl+Z** 或“撤销”按操作顺序撤销最近一次新增、移动、端点调整／缩放、样式修改或删除。切换工具不会清空撤销记录。
6. 按 **Ctrl+C**／**Enter**／“复制”复制带标注图片，或 **Ctrl+S**／“保存”导出 PNG，也可用 **Ctrl+T**／**F3** 转为贴图。绘制拖动过程中禁止输出；各标注模式双击均不会误触复制。

点击工具栏 **序号**，在选区空白处单击，依次放置 **1、2、3…** 圆底数字；每次新截图从 1 开始，切换工具不重置。默认红底白字、直径 48 px，可选择颜色和 24／28／36／48 px 直径；浅色底使用黑字，多位数字自动缩小以适应圆形。

拖动已有序号移动位置，Delete 删除，Ctrl+Z 撤销；下一编号取现有序号最大值加 1，删除中间项不重排，删除或撤销最后一项后可复用该编号。序号随复制、PNG 保存和贴图一起输出，OCR／翻译仍识别原图。使用按钮进入序号工具，不增加单字母快捷键。
无需切换工具即可拖动截图框边缘或八个控制点调整范围；这些位置优先操作截图框，重叠的标注端点可先扩大截图范围再编辑。选区内部仍按当前工具绘制或编辑标注。**再次点击当前标注工具**退出绘制，随后可拖动框内移动截图范围。一次拖动开始后不会中途切换操作对象。

调整截图范围时，标注保持在原图位置，超出选区的部分被裁剪；再次扩大选区可以重新看到，裁剪边缘不会生成新的箭头头部。截图选区及控制点不进入导出图片。复制、保存、贴图、OCR 和翻译均使用调整后的范围；**Shift+C OCR 和 Shift+T 翻译仍识别原图**，不叠加标注。

标注只在本次截图内保留。按 Esc、右键画面或“取消”放弃整次截图。

## 马赛克

框选截图后，点击 **马赛克**，在选区内拖动框出需要像素化的矩形区域。默认方块大小为 **30 px**，工具栏“粒度”可选 8／16／24／30 px，数值越大方块越粗；粒度独立于矩形、箭头的粗细，马赛克不使用颜色设置，也不增加快捷键。

点击已有马赛克区域选中，拖动内部移动；选中后可拖动八个控制点缩放。支持 **Delete** 删除、**Ctrl+Z** 撤销新增、移动、缩放、粒度修改和删除，再次点击“马赛克”退出工具。截图框边缘优先调整整个截图范围。

马赛克从冻结原图计算各方块平均颜色，边缘残块同样参与处理。按创建顺序覆盖图片及更早的标注；更晚添加的矩形、箭头和序号可画在马赛克上。调整截图范围只裁剪效果，扩大范围可再次看到原有马赛克。预览、复制、PNG 保存及贴图共用效果，控制点不进入图片。

**OCR／翻译仍读取原图，马赛克不会对识别出的文字脱敏。** 取消截图放弃本次马赛克，不修改原图、不保存编辑历史。

## 滚动长截图

1. 按 **Ctrl+F2**，框选同一个窗口、同一显示器内的滚动内容区，避开固定导航栏、工具栏、页脚和滚动条；宽度至少 32 px，高度至少 64 px。已有标注时先撤销标注。
2. 点击 **长截图**。蓝色边框显示采集范围，范围外变暗；在框内原页面手动缓慢向下滚动，每次保留至少四分之一的重叠内容，停顿片刻等待拼接。遮罩允许鼠标穿透，工具不自动滚动页面。
3. 右侧实时显示已拼接长图，绿色框标示当前已接入的画面位置，尚未稳定或无法匹配时变为橙色。右侧空间不足时预览移到左侧或屏内，也可拖动预览避开内容；底部操作条空间不足时移到上方或屏内。操作条显示尺寸、帧数和状态。重复画面不会追加；滚动过快、向上滚动或内容无法唯一匹配时保留已有部分，可缓慢回到上次位置再向下滚动，或直接完成。
4. 点击操作条 **完成** 或再次按 **Ctrl+F2**，补采最后的稳定画面后，直接将原分辨率长图复制到剪贴板并关闭采集界面，不再打开结果预览页。随后可在其他应用粘贴图片。
5. 复制失败时保留已拼接内容，可再次点击 **完成** 重试。末段无法拼接时只复制成功部分，并通过托盘提示说明。

点击操作条“取消”会丢弃本次采集，不修改剪贴板、不写文件，等待中的复制重试也会取消；操作条或实时预览获得键盘焦点时可按 Esc 取消。在原页面滚动时，Esc 仍由原应用处理。

采集中不要移动或缩放原窗口。原窗口被遮挡、最小化或位置改变时暂停追加，恢复原状态后可继续；显示器布局变化会取消采集。现有贴图在采集中保持隐藏，结束后恢复。初始画面来自框选时截图，后续只采集选中区域；固定栏不自动去除。视频、持续动画、重复条纹及大段纯色内容可能无法可靠拼接。

长截图最高 30000 px、最多 3200 万像素，达到任一上限后保留已有结果并提示完成；仅支持纵向向下滚动。采集面板需要 Windows 10 2004 或更新版本，以从截图中排除自身，依据见 [微软 SetWindowDisplayAffinity 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity) 。

## 区域录屏

1. 按 **Ctrl+F2**，在同一显示器内框选至少 16 × 16 px 的区域，点击 **录屏**。已有截图标注时先撤销；录屏不叠加标注。
2. 直接倒计时 3 秒后开始，不弹出保存对话框。录制范围固定，不跟随窗口移动。
3. 红色边框显示范围，操作条显示时长和输出尺寸。录制包含鼠标指针，不录系统声音或麦克风；边框和操作条从录制中排除。系统可能另外显示采集提示边框。
4. 点击 **完成** 或按 **Ctrl+F2** 结束录制并复制 GIF，成功后关闭录屏界面。复制失败保留动图，点击 **完成** 重试；重复点击不会重复复制。
5. 点击 **取消** 丢弃本次录制；操作条获得焦点时也可按 Esc。原应用获得焦点时，Esc 仍交由原应用处理。编码结束或等待剪贴板时也可以取消，取消后不会继续复制。

输出为循环播放的 GIF 动图，目标 30 fps；根据实际采集时间戳写入帧间隔，繁忙时帧率可能降低，播放速度还取决于查看软件。尺寸等比限制在 1920×1080 内、不放大小选区。GIF 每帧最多 256 色，渐变和复杂画面会有色彩损失，适合短操作演示。区域外画面不写入动图；显示器帧仅用于内存中的区域裁剪。当前只支持 SDR，HDR、受保护内容和独占全屏不承诺兼容。

录制与普通截图／长截图互斥，贴图在录制中隐藏、结束后恢复。关闭操作条、锁屏、显示器布局变化、录屏操作条所在显示器 DPI 变化以及正常退出程序按取消处理，放弃本次录制。

动图逐帧写入系统临时目录中的独立缓存，不选择保存目录、不自动保存到用户目录。完成后按 GIF 文件格式放入剪贴板，接收应用需要支持文件／GIF 粘贴；不使用静态首帧代替动图。成功复制后临时 GIF 保留供粘贴读取，因此退出程序后仍可粘贴；取消或采集／编码失败删除本次缓存，复制失败可重试或取消。不会自动上传、后台录制或安装外部编码器。

## 贴图

按 **Ctrl+F2** 框选后，点击“贴图”或按 **Ctrl+T**／**F3**，将选区变为置顶图片并结束截图。矩形、箭头、序号及马赛克会保留在贴图中；创建贴图不改写剪贴板、不自动保存文件。Ctrl+T／F3 仅在截图界面内生效，使用当前选区，不读取剪贴板；在其他应用中 Ctrl+V 仍为正常粘贴。

- **拖动**：移动贴图，支持跨显示器移动。
- **外观**：图片外侧显示 1 个物理像素的细蓝色边框及柔和蓝色外阴影，不遮盖图片；复制和保存不包含边框、阴影。100% 显示时图片仍保持原始像素尺寸。
- **滚轮**：等比例缩放；右键菜单“恢复原始比例”恢复 100% 原始像素比例。大图首次显示会缩小以适配所在显示器工作区；放大的图片可移出屏幕部分区域，但始终保留可操作部分。
- **Ctrl+C**：复制当前贴图；**Ctrl+S**：保存 PNG。无论显示比例如何，输出保留原始分辨率。
- **双击鼠标左键**或 **Esc**：关闭当前贴图；右键菜单也提供复制、保存、恢复比例和关闭。
- 可同时打开多张贴图，分别移动、缩放与关闭；托盘菜单“关闭全部贴图”可统一关闭。关闭贴图不会退出主程序。

再次截图会包含当时屏幕上可见的贴图。截图操作期间，原贴图窗口暂时隐藏，结束或取消后恢复。贴图只在本次运行期间保留，退出程序即关闭；不自动保存历史。贴图中的标注已经合成为图片，无法在贴图内继续编辑。

## 快捷键速查

全局仅注册 **Ctrl+F2**：开始截图；长截图采集中再次按下则完成并复制；录屏中再次按下则完成并复制 GIF，倒计时期间按下则取消。

截图界面内：

- **Ctrl+C** 或 **Enter**：复制当前选区图片并结束截图。
- **Ctrl+T** 或 **F3**：将当前选区转为置顶贴图并结束截图。
- **Ctrl+S**：保存 PNG。
- **Shift+C**：OCR 识别并复制文字。
- **Shift+T**：OCR 后打开翻译。
- **Shift + 拖动**：新矩形为正方形；箭头绘制和端点调整限制方向。
- **Delete**：删除选中标注。
- **Ctrl+Z**：撤销标注操作。
- **Esc**：取消截图或正在进行的 OCR。

贴图窗口内：**Ctrl+C** 复制图片，**Ctrl+S** 保存 PNG，**Esc** 或鼠标左键双击关闭；滚轮缩放、拖动移动，右键菜单恢复原始比例。

翻译窗口内：**Esc** 在请求中取消，空闲时关闭；翻译设置窗口内 **Esc** 关闭。颜色、粗细、翻译设置、复制完整原文／译文、重新翻译、恢复贴图比例、关闭全部贴图及退出程序使用按钮或菜单，未设置专用快捷键。

## 配置有道翻译

1. 在[有道智云](https://ai.youdao.com/) 开通文本翻译服务，创建应用并绑定该服务，获取应用 ID 和应用密钥。
2. 右键 Snap Tool 托盘图标，选择“翻译设置…”，填写应用凭据并保存。对照窗口也有“翻译设置”入口。保存只保存凭据，不调用接口或验证余额。
3. 使用 Shift+T 翻译选区；未配置或接口失败时，对照窗口保留 OCR 原文，配置后可点击“翻译”重试。点击“复制原文”或“复制译文”才会修改剪贴板。

仅主动翻译时向固定接口 `https://openapi.youdao.com/api` 发送文字，不发送截图、不自动保存原文或译文。服务可能按用量收费；网络、账户权限、余额与限流都会影响请求。单次最多 5000 个 Unicode 字符，超出时提示缩小选区或手动分段；20 秒超时后不自动重试，也不切换其他服务。取消可以阻止本地结果更新，但无法撤回已经发出的请求或保证取消计费。接口依据见[有道官方文档](https://ai.youdao.com/DOCSIRMA/html/trans/api/wbfy/index.html) 。

配置位于当前用户的 `%LOCALAPPDATA%\SnapTool\translation.json`，应用 ID 与使用 Windows DPAPI 加密的密钥存于此文件。密钥不随便携包分发，换电脑或 Windows 用户后需重新填写；不必将密钥发送到聊天或写进源码。当前 OCR 重点支持中英文，翻译服务的更多语种支持不代表截图 OCR 已全部适配。

## 截图操作说明

工具栏显示在选区附近。尺寸标签使用实际像素，不是缩放后的界面单位。选区可以跨越显示器；显示器之间没有画面的空隙输出为黑色。

右键托盘图标可以截图、重新注册 Ctrl+F2、关闭全部贴图或退出；双击托盘图标也可截图。快捷键冲突时会提示，释放其他程序占用后可通过托盘重新注册。程序仅允许单实例。

截图期间保留一个任务栏入口，可以使用 Alt+Tab 切回截图；结束后入口关闭，程序回到托盘。

可以传入 `--capture` 在启动时直接进入截图。已经运行时，再次启动只提示使用现有实例。

取消截图不会写入图片或改变剪贴板。取消保存对话框返回选区；输出失败保留选区以便重试。复制完成后图片保留在 Windows 剪贴板，保存仅写入选择的文件位置。

## 开发与构建

需要 Windows 10 2004（19041）或更新版本的 x64 系统与 `global.json` 指定的 .NET 10 SDK。OCR 使用 RapidOcrNet 4.2.0、ONNX Runtime CPU、SkiaSharp 和 PP-OCRv5 中文模型；依赖版本记录于项目的 `packages.lock.json`。录屏通过 Windows SDK 的 Windows Graphics Capture 和 BitmapEncoder 调用系统采集与 GIF 编码能力，WinRT SDK 投影随便携包分发；许可文件随应用放入 `licenses/`，模型来源和校验清单见 [models/README.md](models/README.md) 。

在项目根目录运行：

```powershell
# 没有匹配 SDK 时，可仅安装到项目 .tools 目录
powershell -ExecutionPolicy Bypass -File scripts/setup-sdk.ps1

# 首次克隆后下载固定版本 OCR 模型并校验 SHA256
powershell -ExecutionPolicy Bypass -File scripts/setup-ocr-models.ps1 -Download

# 编译并运行自动回归
powershell -ExecutionPolicy Bypass -File scripts/build.ps1

# 验证后生成自包含应用目录
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -Publish
```

在可交互的 Windows 桌面上，可追加 `-DesktopChecks` 执行原生贴图、自动选窗、长截图与录屏检查，也可与 `-Publish` 一起使用。检查会短暂显示并关闭合成测试窗口，长截图检查只采集测试窗口内部，不读取真实剪贴板；录屏检查使用合成窗口验证采集、裁剪、编码及停止／取消；普通回归和桌面检查分别报告结果，任一失败都会停止后续打包并返回非零退出码。默认构建跳过桌面检查，适用于无人值守环境。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -DesktopChecks
```

仓库提供源码、测试、依赖锁文件、构建脚本及模型校验清单，不包含 SDK、模型缓存和运行包。构建脚本优先使用 `.tools/dotnet/dotnet.exe`，再使用 PATH 中的 SDK。首次构建需要从 NuGet 获取依赖和运行时包；模型通过上述脚本下载，构建前校验四个模型文件的 SHA256。交付目录为 `dist/SnapTool/`；运行时无需另装 .NET 或 OCR 软件，但须保留目录内的 DLL、`models/` 和 `licenses/`。模型加载路径以程序目录为准，不依赖启动时的工作目录。

自动回归使用合成像素和任务临时文件；不读取真实剪贴板、不捕获桌面。界面测试窗口入口：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/test-ui.ps1
# 需要在右侧显示器显示第二个测试窗口时
powershell -ExecutionPolicy Bypass -File scripts/test-ui.ps1 -Secondary
```

在测试窗口中按 Ctrl+F2 截取色块或文字，然后按 Ctrl+V 显示剪贴板图片和尺寸或识别文字；图片检查会将测试图片写入 `.tmp/ui-validation/clipboard.png`。仅用于本项目测试内容。

测试窗口用 Alt+F4 关闭。重新构建前先关闭测试窗口，重新打包前从托盘退出正在运行的交付程序，避免 Windows 文件锁阻止替换。
